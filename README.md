# TestsDGT - Tests de Conducir de la DGT Oficiales y Gratuitos

Realiza los **tests de conducir de la DGT oficiales** de forma totalmente gratuita. Esta web te permite practicar con los mismos test que ofrece la DGT en [revista.dgt.es/es/test/](https://revista.dgt.es/es/test/), sin necesidad de registro y con todas las funcionalidades que necesitas para prepararte tu examen de conducir.

## ✨ Características

- **100% Gratis y sin registro**: Accede inmediatamente a todos los tests de la DGT sin crear cuenta
- **Progreso guardado en el navegador**: Tu avance se guarda automáticamente en tu dispositivo
- **Repetir preguntas fallidas**: Practica solo con las preguntas que necesitas mejorar
- **Copiar preguntas para IA**: Puedes copiar cualquier pregunta y enviársela a una IA para que te explique la respuesta
- **Tests oficiales de la DGT**: Mismo contenido que la plataforma oficial de la DGT
- **Código abierto**: Proyecto totalmente transparente y disponible en GitHub

## 🎯 Objetivos del Proyecto

Este proyecto nace con el objetivo de facilitar el acceso a los tests de conducir de la DGT de forma gratuita y abierta. Queremos que cualquier persona pueda prepararse para su examen de conducir sin barreras económicas ni de registro.

El proyecto es **código abierto** y estamos **abiertos a Pull Requests (PRs)**. Si quieres contribuir, reportar bugs o sugerir mejoras, siéntete libre de hacerlo.

## 🛠️ Desarrollo Local

Si quieres contribuir al proyecto o modificarlo, sigue estos pasos para ejecutarlo en tu entorno local:

### Requisitos previos
- Node.js instalado (versión 18 o superior recomendada)
- npm o yarn

### Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/lordor5/TestsDGT.git
cd TestsDGT
```

2. Instala las dependencias:
```bash
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
```

El servidor se iniciará en `http://localhost:3000` y podrás ver los cambios en tiempo real.

### Comandos disponibles

| Comando                | Acción                                             |
| :--------------------- | :------------------------------------------------- |
| `npm install`          | Instala dependencias                               |
| `npm run dev`          | Inicia servidor de desarrollo en `localhost:3000`  |
| `npm run build`        | Compila el sitio para producción en `./dist/`      |
| `npm run preview`      | Previsualiza la compilación localmente             |
| `npm run astro ...`    | Ejecuta comandos CLI de Astro                      |
| `npm run astro --help` | Obtiene ayuda usando el CLI de Astro               |
